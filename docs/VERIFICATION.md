## 新架构覆盖

核心测试覆盖：空库不生成领域；无步骤、单目标、多目标、嵌套目标的等权进度；完成/取消不会修改知识节点；稳定 id 的重命名与移动；目标三层、知识五层上限；循环与跨领域父节点拒绝；自关联、无向重复关系拒绝；步骤关联去重；Space、Goal、Step、KnowledgeNode 的级联清理；并发版本冲突与配额不足回滚。

迁移与备份覆盖：真实 v2 IndexedDB 升级；非法旧记录导致整个升级事务回滚，数据库仍为 v2，原记录保持；原始数据救援导出不依赖新 schema；旧备份转为 v3；新实体完整往返；深层旧路径合并并提示；无效 schema、孤儿引用拒绝。原有图片、历史、调度参数、SHA-256、未知版本、恢复回滚、v1 迁移测试保留。

桌面/手机各七项新流程覆盖：

1. 真正空白首页，自定义领域创建、编辑、两次删除确认。
2. 三层目标、步骤新增编辑删除、完成取消、真实进度与递归删除。
3. 五层知识树，稳定 id、重命名、移动、折叠和笔记。
4. 节点关系、图谱高亮和缩放、步骤正向关联、节点反向任务、删除清理。
5. v3 完整备份的全部实体计数、确认前不覆盖、恢复后保留。
6. 3,000 节点的树与图初始仅显示 100 个，按批展开；320px 窄屏无整页横向溢出。
7. 真正浏览器 v2 → v3，旧卡片保留且不创建没有内容的固定科目。
