## 完整使用流程

文字、公式与两面图片录入 → 保存 → 刷新后保留 → 搜索 → 开始复习 → 答案默认不在 DOM → 放大图片 → 展开答案 → 评分 → 刷新 → 撤销并逐字段比对 → 再评分 → 导出含图片备份 → 新增临时内容 → 校验备份 → 确认覆盖前禁用恢复 → 先导出现有数据 → 覆盖恢复 → 比较图片字节、卡片与全部历史 → 编辑并确认调度不重置。

另外验证了粘贴截图、拖入图片、沿用科目、待整理不入队、设置刷新持久化、非法 JSON 提示、模拟配额不足时保留表单、键盘空格展开与数字评分、跨午夜新学额度恢复、长公式和长文字无整页横向溢出。批量录入验证了：保存并继续下一条沿用科目与来源、同一图片复用到另一面只占一份存储、Ctrl+Enter 保存、重复问题先确认、未保存内容刷新后按草稿恢复。英语科目验证了：类型为单词与句子、录入框标题与复习展开按钮随类型变化、单词单行速录回车连录、切换科目后类型自动跟随、复习提示按类型显示。删除验证了：评分后删除内容，卡片与复习历史一并清除。分类验证了：数学录入可选预设分类、内容库按分类筛选、熟悉程度标记与徽标显示、复习页显示分类、英语不出现分类选择。完整流程没有发起第三方请求。
