# 知识卡片入口与双框编辑改造

领域默认进入本领域的知识卡片。首页树图放大并保留节点字号，点击节点直接进入该知识点阅读；知识库继续汇总所有领域。目标、步骤和进度界面移除，Goals、KnowledgeLinkPicker、ProgressView 及专用样式清理；旧数据通过备份保留。

“编辑知识树”采用左右等宽、独立的白色圆角方框：左目录、右图谱。图谱的展示根使用领域名称，连接已有根节点，不写入数据库或占五层深度。点击目录或图谱节点后左 Markdown、右实时预览，返回保留目录状态，图片和未保存保护继续保留。
