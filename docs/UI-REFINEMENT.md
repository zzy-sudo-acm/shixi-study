# 前端与知识图谱改进

本次改动保留本地数据与复习调度，在现有蓝灰色复习本风格上增加知识卡片、交互反馈、知识族谱点选和数学关联图谱。英语隐藏分类，仅保留单词、句子两种录入与筛选方式。

## 数据兼容

- `relatedIds` 是可选字段，旧卡片和旧备份不需要预先迁移。关联在 IndexedDB 同一事务中更新两端，移除连接、改变科目或删除卡片时清理另一端。
- 导出和恢复校验关联目标、科目、自关联、重复与双向一致性。原有图片、调度和历史校验继续保留。
- 现有分类路径保留，界面通过树节点选择和父节点移动操作它们。移动后检查整棵子树深度，不允许移入自己的后代。
- 原有英语分类在浏览时隐藏，不批量清除用户数据；重新保存英语卡片时清空该卡片的分类。

## 手机性能

- 内容未展开时不再逐张扫描全部复习历史；筛选结果按依赖缓存，非当前页面与导航中间状态避免重复渲染。
- 导航先更新选中反馈，页面切换使用 React transition。底栏使用布局与绘制隔离、明确的触摸行为，不增加玻璃模糊或持续动画。
- 卡片使用浏览器内容可见性优化；数学图谱按批次展示，无动画物理模拟。
- 隔离 Chromium、390 × 844 视口、CPU 四倍减速、1000 张合成卡片和 20000 条合成历史下，五次“点击到页面更新后第二帧”的中位数由 125ms 变为 110ms。优化前样本：165 / 135 / 118 / 117 / 125ms；优化后：208 / 127 / 108 / 97 / 110ms。首轮没有改善，这组数据仅用于本机模拟对照，不代表真机 INP 或所有手机体验。
- 可用 `node scripts/measure-ui.mjs after` 重跑本地模拟；脚本只创建隔离浏览器数据，输出在忽略的 `test-results/visual/` 中。

## 验证

- TypeScript 检查与 35 项核心测试通过，包括关联事务、删除清理、备份恢复和子树移动。
- 浏览器用例覆盖桌面与手机，包括图片录入、草稿恢复、公式、复习撤销、备份覆盖、英语速录，以及新图谱流程。
- 新增测试覆盖跨分支双向关联、节点改名和移动、含 `&` 的节点路由、320px 窄屏、缩放、隐藏答案和减少动态效果设置。
- 界面检测未报告问题；本地生产构建通过。真机触摸、Safari 和软键盘行为仍需实际设备体验。

不改动远程仓库或线上部署。
