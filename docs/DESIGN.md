# 界面约定

时习是一张日常复习清单。信息按“今日到期 → 今日可新学 → 待整理”展开，所有计数来自本机真实数据。

- 色彩：纸面灰 #f5f7f9、白 #ffffff、墨蓝 #263e58、灰蓝 #5e7184、浅蓝 #e9eff6、提示赭色 #925326。知识关联使用低饱和绿色，与蓝色归属线区分。
- 字体：系统中文黑体用于操作与正文，宋体仅用于“时习”和首页主标题；不请求外部字体。
- 桌面：紧凑左侧导航，右侧限制阅读宽度；首页一个主要行动区，下方四个科目清单行。手机：顶端品牌、底部导航、单列内容。
- 提问、答案、评分依序出现。答案在展开前不进入 DOM。知识点先回忆，练习题先在纸上做。
- 内容库是可展开的知识卡片：14px 圆角、白纸面、轻阴影，手机单列。标题最多显示三行，展开后保留完整原文。仅展开卡片时读取对应复习历史。
- 数学的树用于组织知识，图用于连接知识。分类通过点选节点和父节点完成；关系在录入页选择已有卡片创建。桌面图谱横向布局，手机改为纵向分支，提供缩放和总览；不用持续运行的力导向模拟。英语仅提供单词与句子。
- 动效围绕操作：导航按压、页面轻入场、卡片与答案展开、树分支指示旋转。不使用循环动画或全屏模糊，遵循减少动态效果的系统设置。
- 手机导航独立限制布局和重绘，优先更新选中项；各页面避免随导航状态重复计算。保存区随表单滚动，避免与底部导航叠加占满屏幕。
- 重点放在复习与知识组织，不添加掌握率或虚构统计。空白是真实的初始状态。

设计复核：拒绝通用营销首屏与数据大屏，把视觉重点收敛为左侧书签式导航和中央问题纸面。功能页沿用同一套字号、间距与按钮。
