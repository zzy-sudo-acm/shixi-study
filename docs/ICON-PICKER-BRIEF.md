# 领域图标选择器

模式：Operate。局部扩展现有领域表单，沿用既有视觉体系；用户已选择“图标预览 + 选择图标”，不创建新视觉世界，不使用 comp 或随机 seed。

## Direction contract

THESIS：领域图标用点选完成，默认图标让用户只填写名称也能创建。

OWN-WORLD：延续纸灰、白色、墨蓝；沿用 24px viewBox、1.7px 线条 SVG 图标和现有焦点样式。

STORY：查看当前图标，展开面板，点选图标或常用 emoji，保存领域。

FIRST VIEWPORT：名称下方是彩色图标预览、当前名称与选择按钮；面板在原表单内展开，手机使用紧凑网格。

FORM：用户钉定的窄范围组件扩展，无 concept-roll seed；保留旧 emoji 和符号，数据库与备份格式不变。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
