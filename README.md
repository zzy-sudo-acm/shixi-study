# 时习 · 个人学习空间

从空白开始，由自己建立学习领域与知识结构。React + TypeScript + Vite + IndexedDB，无需登录、后端或云服务，手机与电脑均可使用。应用版本 2.0.1，数据格式 v3。

## 怎么用

1. 首次打开没有预设内容。在“我的学习空间”点“新建领域”；名称、图标和颜色在领域页的“编辑领域”中修改，“删除领域”也在领域页。图标可预览并点选 12 个线条图标或常用 emoji，也可输入自己的符号；不选择时默认使用书本。首页球体轮播展示真实知识树，领域整张树图卡片可点击进入。
2. 点击领域，直接查看该领域的知识卡片；每张卡片代表一棵根节点知识树，点开卡片后点击节点阅读知识点。首页领域图提供更大的滚动画布，点其中的节点也能直接阅读；知识库汇总全部领域的知识卡片。
3. 点领域页的“编辑知识树”，左侧为文件夹式目录，右侧为节点图，两个方框等宽、并列。节点图的总根节点显示领域名称，把各个根节点连接在下面；它只是展示节点，不写入数据，也不占用五层深度。
4. 目录右上角加号新建根节点，行内三点菜单支持添加子节点、重命名、移动与删除；箭头折叠分支。拖到另一节点上成为其子节点，拖到底部“最外层”回根级；也可用“移动节点”选择位置。所有节点都能有子节点和正文，改名保持稳定 ID。
5. 点击目录名称或编辑图中的节点，切换为左侧白色 Markdown 文本区、右侧实时预览，继续保持等宽双框；“返回目录”恢复原目录状态。支持标题、列表、粗斜体、代码、引用、链接、$公式$ 与图片。图片可通过“插入图片”、粘贴或拖入添加，也支持远程 Markdown 图片。点“保存修改”或在文本区按 Ctrl/Cmd+S 保存；离开或放弃未保存内容时会确认，图片插入期间暂停返回与保存。
6. 目标、步骤与进度界面已移除，旧数据在完整备份中保留。删除领域需两次确认；删除知识分支会说明后代和关联的影响范围。定期在“设置与备份”导出完整备份。

目录和图谱先显示 100 个知识节点，可继续展开；目录支持按名称搜索。移动端两框上下排布，顶部“目录 / 节点图”或“编辑 / 预览”可定位对应区域。首页树图可横向和纵向滚动。本地图片存入 IndexedDB 并纳入备份；远程图片保留 URL，读取需要可访问的网络地址。

## 复习功能的去向

错题、单词、句子等记忆卡片与 FSRS 复习界面已于 2026-10 移除。已有卡片、图片与复习历史不会被删除：它们仍在本机 IndexedDB 中，并继续包含在完整备份里。公式渲染（KaTeX）保留在知识点的 Markdown 中。历史使用说明见 [旧版文档](docs/LEGACY-README.md)。

## 本地运行

需要 Node.js ≥22.12.0 和 pnpm 11.19.0。

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm check       # TypeScript + 全部核心测试
pnpm build       # 生产构建
pnpm preview
pnpm exec playwright install chromium
pnpm test:e2e    # 桌面与手机视口流程
```

Windows 可使用现有 Chrome 验证生产构建：

```powershell
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE='C:\Program Files\Google\Chrome\Application\chrome.exe'
pnpm build
$env:TEST_PRODUCTION='1'
pnpm test:e2e
```

生产测试直接服务 `dist/` 的 `/shixi-study/` 子路径，不提供 SPA 路由回退。测试使用隔离浏览器和合成资料，不操作日常浏览器里的真实数据。

## 数据与备份

所有学习数据保存在当前网站地址、路径和浏览器的 IndexedDB 中。手机与电脑不自动同步；换设备、浏览器或站点地址时使用备份迁移。未保存的录入草稿单独保存在本机，不进入备份。

v3 完整备份包含领域、目标、步骤、知识节点、节点关系、步骤关联，以及全部旧卡片、图片、历史、设置和调度参数。恢复前验证 schema、SHA-256 与全部引用，展示数量和覆盖确认；恢复是整份替换，事务失败会回滚。

旧 IndexedDB 与 v1/v2 备份自动迁移。有实际内容的旧科目生成领域，分类路径转为节点，原卡片与路径完整保留。无法安全迁移时保留旧数据库，提供原始数据副本导出；该副本用于修复，不能直接作为普通备份导入。详见 [数据迁移说明](docs/MIGRATION.md)。

清除浏览器数据、存储回收和设备故障可能丢失本地数据，请将完整备份保存在浏览器之外。备份未加密，单份上限 200 MB；不应提交真实笔记、题目照片或备份。没有 Service Worker，不承诺断网后重新打开。
